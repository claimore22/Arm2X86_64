## LDNT1W (vector plus scalar)

Gather load non-temporal unsigned words

This instruction performs a non-temporal gather load of unsigned words to Active elements of a vector register from memory addresses generated by a vector base plus a 64-bit unscaled scalar register offset. Inactive elements will not cause a read from Device memory or signal faults, and are set to zero in the destination vector.

A non-temporal load is a hint to the system that this data is unlikely to be referenced again soon.

This instruction is illegal when executed in Streaming SVE mode, unless FEAT_SME_FA64 is implemented and enabled.

It has encodings from 2 classes: [32-bit unscaled offset](#iclass_32_bit_unscaled_offset) and [64-bit unscaled offset](#iclass_64_bit_unscaled_offset)

### Operation

[CheckNonStreamingSVEEnabled](shared_pseudocode.html#func_CheckNonStreamingSVEEnabled_0)(); let VL : integer{} = [CurrentVL](shared_pseudocode.html#func_CurrentVL_0)(); let PL : integer{} = VL DIV 8; let elements : integer = VL DIV esize; let mask : bits(PL) = P{}(g); var base : bits(VL); var offset : bits(64); var result : bits(VL); var data : bits(msize); let mbytes : integer{} = msize DIV 8; let contiguous : boolean = FALSE; let nontemporal : boolean = TRUE; let predicated : boolean = TRUE; let tagchecked : boolean = TRUE; let accdesc : [AccessDescriptor](shared_pseudocode.html#type_AccessDescriptor) = [CreateAccDescSVE](shared_pseudocode.html#func_CreateAccDescSVE_5)([MemOp_LOAD](shared_pseudocode.html#enum_MemOp_LOAD), nontemporal, contiguous, predicated, tagchecked); if [AnyActiveElement](shared_pseudocode.html#func_AnyActiveElement_3){PL}(mask, esize) then base = [Z](shared_pseudocode.html#accessor_Z_2){VL}(n); offset = [X](shared_pseudocode.html#accessor_X_2){64}(m); end; for e = 0 to elements-1 do if [ActivePredicateElement](shared_pseudocode.html#func_ActivePredicateElement_4){PL}(mask, e, esize) then let baddr : bits(64) = ZeroExtend{}(base\[e\*:esize\]); let addr : bits(64) = [AddressAdd](shared_pseudocode.html#func_AddressAdd_3)(baddr, offset, accdesc); data = [Mem](shared_pseudocode.html#accessor_Mem_3){msize}(addr, accdesc); result\[e\*:esize\] = Extend{esize}(data, unsigned); else result\[e\*:esize\] = Zeros{esize}; end; end; [Z](shared_pseudocode.html#accessor_Z_2){VL}(t) = result;
