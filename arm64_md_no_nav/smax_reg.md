## SMAX (register)

Signed maximum (register)

This instruction determines the signed maximum of the two source register values and writes the result to the destination register.

### Operation

let operand1 : bits(datasize) = X{}(n); let operand2 : bits(datasize) = X{}(m); let result : integer = Max(SInt(operand1), SInt(operand2)); [X](shared_pseudocode.html#accessor_X_2){datasize}(d) = result\[datasize-1:0\];
