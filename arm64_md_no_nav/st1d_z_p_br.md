## ST1D (scalar plus scalar, single register)

Contiguous store doublewords from vector (scalar index)

This instruction performs a contiguous store of doublewords from elements of a vector register to the memory address generated by a 64-bit scalar base and scalar index that is multiplied by 8 and added to the base address. After each element access the index value is incremented, but the index register is not updated. Inactive elements are not written to memory.

The 128-bit element variant is illegal when executed in Streaming SVE mode, unless FEAT_SME_FA64 is implemented and enabled.

It has encodings from 2 classes: [64-bit element](#iclass_64_bit_element) and [128-bit element](#iclass_128_bit_element)

### Operation

if esize \< 128 then [CheckSVEEnabled](shared_pseudocode.html#func_CheckSVEEnabled_0)(); else [CheckNonStreamingSVEEnabled](shared_pseudocode.html#func_CheckNonStreamingSVEEnabled_0)(); end; let VL : integer{} = [CurrentVL](shared_pseudocode.html#func_CurrentVL_0)(); let PL : integer{} = VL DIV 8; let elements : integer = VL DIV esize; var base : bits(64); let mask : bits(PL) = P{}(g); var offset : bits(64); var addr : bits(64); var src : bits(VL); let mbytes : integer{} = msize DIV 8; let contiguous : boolean = TRUE; let nontemporal : boolean = FALSE; let predicated : boolean = TRUE; let tagchecked : boolean = TRUE; let accdesc : [AccessDescriptor](shared_pseudocode.html#type_AccessDescriptor) = [CreateAccDescSVE](shared_pseudocode.html#func_CreateAccDescSVE_5)([MemOp_STORE](shared_pseudocode.html#enum_MemOp_STORE), nontemporal, contiguous, predicated, tagchecked); if \![AnyActiveElement](shared_pseudocode.html#func_AnyActiveElement_3){PL}(mask, esize) then if n == 31 && [ConstrainUnpredictableBool](shared_pseudocode.html#func_ConstrainUnpredictableBool_1)([Unpredictable_CHECKSPNONEACTIVE](shared_pseudocode.html#enum_Unpredictable_CHECKSPNONEACTIVE)) then [CheckSPAlignment](shared_pseudocode.html#func_CheckSPAlignment_0)(); end; else if n == 31 then [CheckSPAlignment](shared_pseudocode.html#func_CheckSPAlignment_0)(); end; src = [Z](shared_pseudocode.html#accessor_Z_2){VL}(t); end; base = if n == 31 then [SP](shared_pseudocode.html#accessor_SP_1){64}() else [X](shared_pseudocode.html#accessor_X_2){64}(n); offset = [X](shared_pseudocode.html#accessor_X_2){64}(m); addr = [AddressAdd](shared_pseudocode.html#func_AddressAdd_3)(base, UInt(offset) \* mbytes, accdesc); for e = 0 to elements-1 do if [ActivePredicateElement](shared_pseudocode.html#func_ActivePredicateElement_4){PL}(mask, e, esize) then [Mem](shared_pseudocode.html#accessor_Mem_3){msize}(addr, accdesc) = src\[e\*:esize\]\[msize-1:0\]; end; addr = [AddressIncrement](shared_pseudocode.html#func_AddressIncrement_3)(addr, mbytes, accdesc); end;
