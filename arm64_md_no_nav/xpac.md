## XPACD, XPACI, XPACLRI

Strip Pointer Authentication Code

This instruction removes the Pointer Authentication Code from an address. The address is in the specified general-purpose register for <span class="asm-code">XPACI</span> and <span class="asm-code">XPACD</span>, and is in LR for <span class="asm-code">XPACLRI</span>.

The <span class="asm-code">XPACD</span> instruction is used for data addresses, and <span class="asm-code">XPACI</span> and <span class="asm-code">XPACLRI</span> are used for instruction addresses.

It has encodings from 2 classes: [Integer](#iclass_integer) and [System](#iclass_system)
