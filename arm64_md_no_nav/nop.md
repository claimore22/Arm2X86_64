## NOP

No operation

This instruction does nothing, other than advance the value of the program counter by 4. This instruction can be used for instruction alignment purposes.

<div class="note">

------------------------------------------------------------------------

#### Note

The timing effects of including a <span class="asm-code">NOP</span> instruction in a program are not guaranteed. It can increase execution time, leave it unchanged, or even reduce it. Therefore, <span class="asm-code">NOP</span> instructions are not suitable for timing loops.

------------------------------------------------------------------------
