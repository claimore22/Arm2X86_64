## MOV (scalar, predicated)

Move general-purpose register to vector elements (predicated)

This instruction moves the general-purpose scalar source register to each Active element in the destination vector. Inactive elements in the destination vector register remain unmodified.

This is an alias of [CPY (scalar)](cpy_z_p_r.html). This means:

- The encodings in this description are named to match the encodings of [CPY (scalar)](cpy_z_p_r.html).
- The description of [CPY (scalar)](cpy_z_p_r.html) gives the operational pseudocode, any <span class="arm-defined-word">constrained unpredictable</span> behavior, and any operational information for this instruction.
