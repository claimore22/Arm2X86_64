## APAS

Associate physical address space This instruction associates a physical address space with a memory-mapped location that is protected by a memory-side physical address space filter. For more information, see APAS, Associate PA space. This is an alias of [SYS](sys.html). This means: - The encodings in this description are named to match the encodings of [SYS](sys.html). - The description of [SYS](sys.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [SYS](sys.html) gives the operational pseudocode for this instruction.
