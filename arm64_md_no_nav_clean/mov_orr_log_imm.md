## MOV (bitmask immediate)

Move bitmask immediate value This instruction writes a bitmask immediate value to a register. This is an alias of [ORR (immediate)](orr_log_imm.html). This means: - The encodings in this description are named to match the encodings of [ORR (immediate)](orr_log_imm.html). - The description of [ORR (immediate)](orr_log_imm.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [ORR (immediate)](orr_log_imm.html) gives the operational pseudocode for this instruction.
