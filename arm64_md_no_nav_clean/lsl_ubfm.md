## LSL (immediate)

Logical shift left (immediate) This instruction shifts a register value left by an immediate number of bits, shifting in zeros, and writes the result to the destination register. This is an alias of [UBFM](ubfm.html). This means: - The encodings in this description are named to match the encodings of [UBFM](ubfm.html). - The description of [UBFM](ubfm.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [UBFM](ubfm.html) gives the operational pseudocode for this instruction.
