## MUL

Multiply This instruction multiplies two register values and writes the result to the destination register. This is an alias of [MADD](madd.html). This means: - The encodings in this description are named to match the encodings of [MADD](madd.html). - The description of [MADD](madd.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [MADD](madd.html) gives the operational pseudocode for this instruction.
