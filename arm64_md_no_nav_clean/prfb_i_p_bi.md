## PRFB (scalar plus immediate)

Contiguous prefetch bytes (immediate index) This instruction prefetches contiguous byte elements from the memory address generated by a 64-bit scalar base and immediate index in the range -32 to 31 that is multiplied by the vector's in-memory size, irrespective of predication, and added to the base address. The \ operand specifies the prefetch hint as follows: - Access type: - PLD for prefetch for load. - PST for prefetch for store. - Target cache level: - L1 for Level 1 cache. - L2 for Level 2 cache. - L3 for Level 3 cache. - Policy: - KEEP for retained or temporal prefetch, allocated in the cache normally. - STRM for streaming or non-temporal prefetch, for data that is used only once.
