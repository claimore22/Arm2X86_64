## FMOV (zero, unpredicated)

Move floating-point +0.0 to vector elements (unpredicated) This instruction unconditionally broadcasts the floating-point constant +0.0 into each element of the destination vector. This instruction is unpredicated. This is a pseudo-instruction of [DUP (immediate)](dup_z_i.html). This means: - The encodings in this description are named to match the encodings of [DUP (immediate)](dup_z_i.html). - The assembler syntax is used only for assembly, and is not used on disassembly. - The description of [DUP (immediate)](dup_z_i.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.
