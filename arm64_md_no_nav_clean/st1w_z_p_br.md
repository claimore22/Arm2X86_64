## ST1W (scalar plus scalar, single register)

Contiguous store words from vector (scalar index) This instruction performs a contiguous store of words from elements of a vector register to the memory address generated by a 64-bit scalar base and scalar index that is multiplied by 4 and added to the base address. After each element access the index value is incremented, but the index register is not updated. Inactive elements are not written to memory. The 128-bit element variant is illegal when executed in Streaming SVE mode, unless FEAT_SME_FA64 is implemented and enabled. It has encodings from 2 classes: [32-bit and 64-bit elements](#iclass_32_bit_and_64_bit_elements) and [128-bit element](#iclass_128_bit_element)
