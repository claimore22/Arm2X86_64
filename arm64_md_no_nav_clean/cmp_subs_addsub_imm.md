## CMP (immediate)

Compare (immediate) This instruction subtracts an optionally-shifted immediate value from a register value. It updates the condition flags based on the result, and discards the result. This is an alias of [SUBS (immediate)](subs_addsub_imm.html). This means: - The encodings in this description are named to match the encodings of [SUBS (immediate)](subs_addsub_imm.html). - The description of [SUBS (immediate)](subs_addsub_imm.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [SUBS (immediate)](subs_addsub_imm.html) gives the operational pseudocode for this instruction.
