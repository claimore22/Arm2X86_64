## ST4B (scalar plus scalar)

Contiguous store four-byte structures from four vectors (scalar index) This instruction performs a contiguous store of four-byte structures, each from the same element number in four vector registers to the memory address generated by a 64-bit scalar base and a 64-bit scalar index register and added to the base address. After each structure access the index value is incremented by four. The index register is not updated by the instruction. Each predicate element applies to the same element number in each of the four vector registers, or equivalently to the four consecutive bytes in memory that make up each structure. Inactive structures are not written to memory.
