## TRCIT

Trace instrumentation This instruction generates an instrumentation trace packet that contains the value of the provided register. For more information, see TRCIT, Trace Instrumentation. This is an alias of [SYS](sys.html). This means: - The encodings in this description are named to match the encodings of [SYS](sys.html). - The description of [SYS](sys.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [SYS](sys.html) gives the operational pseudocode for this instruction.
