## CNEG

Conditional negate This instruction returns, in the destination register, the negated value of the source register if the condition is TRUE, and otherwise returns the value of the source register. This is an alias of [CSNEG](csneg.html). This means: - The encodings in this description are named to match the encodings of [CSNEG](csneg.html). - The description of [CSNEG](csneg.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [CSNEG](csneg.html) gives the operational pseudocode for this instruction.
