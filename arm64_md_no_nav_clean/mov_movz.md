## MOV (wide immediate)

Move wide immediate value This instruction moves a 16-bit immediate value to a register. This is an alias of [MOVZ](movz.html). This means: - The encodings in this description are named to match the encodings of [MOVZ](movz.html). - The description of [MOVZ](movz.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [MOVZ](movz.html) gives the operational pseudocode for this instruction.
