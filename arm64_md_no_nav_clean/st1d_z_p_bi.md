## ST1D (scalar plus immediate, single register)

Contiguous store doublewords from vector (immediate index) This instruction performs a contiguous store of doublewords from elements of a vector register to the memory address generated by a 64-bit scalar base and immediate index in the range -8 to 7 that is multiplied by the vector's in-memory size, irrespective of predication, and added to the base address. Inactive elements are not written to memory. The 128-bit element variant is illegal when executed in Streaming SVE mode, unless FEAT_SME_FA64 is implemented and enabled. It has encodings from 2 classes: [64-bit element](#iclass_64_bit_element) and [128-bit element](#iclass_128_bit_element)
