## FMINNMP

Floating-point minimum number pairwise This instruction calculates the minimum value of each pair of adjacent floating-point elements within each source vector, and interleaves the results from corresponding lanes. The interleaved result values are destructively placed in the first source vector. Regardless of the value of FPCR.AH, the behavior is as follows for each pairwise operation: - Negative zero compares less than positive zero. - If one element is numeric and the other is a quiet NaN, the result is the numeric value. - When FPCR.DN is 0, if either element is a signaling NaN or if both elements are NaNs, the result is a quiet NaN. - When FPCR.DN is 1, if either element is a signaling NaN or if both elements are NaNs, the result is Default NaN.
