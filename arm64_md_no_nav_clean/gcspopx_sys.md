## GCSPOPX

Guarded Control Stack pop exception return record This instruction loads an exception return record from the location indicated by the current GCS pointer register, checks that the record is an exception return record, and increments the pointer by the size of a Guarded Control Stack exception return record. For more information, see GCSPOPX, Guarded Control Stack Pop exception return record. This is an alias of [SYS](sys.html). This means: - The encodings in this description are named to match the encodings of [SYS](sys.html). - The description of [SYS](sys.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [SYS](sys.html) gives the operational pseudocode for this instruction.
