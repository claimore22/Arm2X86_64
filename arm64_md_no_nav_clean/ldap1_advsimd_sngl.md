## LDAP1 (SIMD&FP)

Load-acquire RCpc one single-element structure to one lane of one register This instruction loads a single-element structure from memory and writes the result to the specified lane of the SIMD&FP register without affecting the other bits of the register. The instruction has memory ordering semantics, as described in Load-Acquire, Load-AcquirePC, and Store-Release, except that: - There is no ordering requirement, separate from the requirements of a Load-AcquirePC or a Store-Release, created by having a Store-Release followed by a Load-AcquirePC instruction. - The reading of a value written by a Store-Release by a Load-AcquirePC instruction by the same observer does not make the write of the Store-Release globally observed. This difference in memory ordering is not described in the pseudocode. For information about addressing modes, see Load/Store addressing modes. Depending on the settings in the CPACR_EL1, CPTR_EL2, and CPTR_EL3 registers, and the current Security state and Exception level, an attempt to execute the instruction might be trapped.
