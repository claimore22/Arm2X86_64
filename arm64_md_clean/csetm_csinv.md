## CSETM

Conditional set mask This instruction sets all bits of the destination register to 1 if the condition is TRUE, and otherwise sets all bits to 0. This is an alias of [CSINV](csinv.html). This means: - The encodings in this description are named to match the encodings of [CSINV](csinv.html). - The description of [CSINV](csinv.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [CSINV](csinv.html) gives the operational pseudocode for this instruction.
