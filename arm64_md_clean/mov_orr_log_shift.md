## MOV (register)

Move register value This instruction copies the value in a source register to the destination register. This is an alias of [ORR (shifted register)](orr_log_shift.html). This means: - The encodings in this description are named to match the encodings of [ORR (shifted register)](orr_log_shift.html). - The description of [ORR (shifted register)](orr_log_shift.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [ORR (shifted register)](orr_log_shift.html) gives the operational pseudocode for this instruction.
