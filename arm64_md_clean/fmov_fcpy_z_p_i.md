## FMOV (immediate, predicated)

Move floating-point immediate to vector elements (predicated) This instruction moves a floating-point immediate into each Active element in the destination vector. Inactive elements in the destination vector register remain unmodified. This is an alias of [FCPY](fcpy_z_p_i.html). This means: - The encodings in this description are named to match the encodings of [FCPY](fcpy_z_p_i.html). - The description of [FCPY](fcpy_z_p_i.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [FCPY](fcpy_z_p_i.html) gives the operational pseudocode for this instruction.
