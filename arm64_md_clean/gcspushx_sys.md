## GCSPUSHX

Guarded Control Stack push exception return record This instruction decrements the current GCS pointer register by the size of a Guarded Control Stack exception return record and stores an exception return record to the Guarded Control Stack. For more information, see GCSPUSHX, Guarded Control Stack Push exception return record. This is an alias of [SYS](sys.html). This means: - The encodings in this description are named to match the encodings of [SYS](sys.html). - The description of [SYS](sys.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [SYS](sys.html) gives the operational pseudocode for this instruction.
