## PSSBB

Physical speculative store bypass barrier This instruction is a memory barrier that prevents speculative loads from bypassing earlier stores to the same physical address under certain conditions. For more information and details of the semantics, see Physical Speculative Store Bypass Barrier (PSSBB). This is an alias of [DSB](dsb.html). This means: - The encodings in this description are named to match the encodings of [DSB](dsb.html). - The description of [DSB](dsb.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [DSB](dsb.html) gives the operational pseudocode for this instruction.
