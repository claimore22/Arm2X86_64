## LD1D (scalar plus vector)

Gather load doublewords to vector (vector index) This instruction performs a gather load of doublewords to Active elements of a vector register from memory addresses generated by a 64-bit scalar base plus vector index. The index values are optionally first sign-extended or zero-extended from 32 to 64 bits and then optionally multiplied by 8. Inactive elements will not cause a read from Device memory or signal faults, and are set to zero in the destination vector. This instruction is illegal when executed in Streaming SVE mode, unless FEAT_SME_FA64 is implemented and enabled. It has encodings from 4 classes: [32-bit unpacked scaled offset](#iclass_32_bit_unpacked_scaled_offset) , [32-bit unpacked unscaled offset](#iclass_32_bit_unpacked_unscaled_offset) , [64-bit scaled offset](#iclass_64_bit_scaled_offset) and [64-bit unscaled offset](#iclass_64_bit_unscaled_offset)
