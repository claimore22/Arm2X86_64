## LD3B (scalar plus immediate)

Contiguous load three-byte structures to three vectors (immediate index) This instruction performs a contiguous load of three-byte structures, each to the same element number in three vector registers from the memory address generated by a 64-bit scalar base and an immediate index that is a multiple of 3 in the range -24 to 21 that is multiplied by the vector's in-memory size, irrespective of predication. Each predicate element applies to the same element number in each of the three vector registers, or equivalently to the three consecutive bytes in memory that make up each structure. Inactive elements will not cause a read from Device memory or signal a fault, and the corresponding element is set to zero in each of the three destination vector registers.
