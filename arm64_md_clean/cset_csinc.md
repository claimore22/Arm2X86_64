## CSET

Conditional set This instruction sets the destination register to 1 if the condition is TRUE, and otherwise sets it to 0. This is an alias of [CSINC](csinc.html). This means: - The encodings in this description are named to match the encodings of [CSINC](csinc.html). - The description of [CSINC](csinc.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [CSINC](csinc.html) gives the operational pseudocode for this instruction.
