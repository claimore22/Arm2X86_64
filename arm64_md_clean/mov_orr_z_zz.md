## MOV (vector, unpredicated)

Move vector register (unpredicated) This instruction copies the contents of the source vector register to the destination vector register. This instruction is unpredicated. This is an alias of [ORR (vectors, unpredicated)](orr_z_zz.html). This means: - The encodings in this description are named to match the encodings of [ORR (vectors, unpredicated)](orr_z_zz.html). - The description of [ORR (vectors, unpredicated)](orr_z_zz.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [ORR (vectors, unpredicated)](orr_z_zz.html) gives the operational pseudocode for this instruction.
