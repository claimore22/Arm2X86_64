## NGC

Negate with carry This instruction negates the sum of a register value and the value of NOT (Carry flag), and writes the result to the destination register. This is an alias of [SBC](sbc.html). This means: - The encodings in this description are named to match the encodings of [SBC](sbc.html). - The description of [SBC](sbc.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [SBC](sbc.html) gives the operational pseudocode for this instruction.
