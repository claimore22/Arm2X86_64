## FLOGB

Floating-point base 2 logarithm as integer This instruction returns the signed integer base 2 logarithm of each floating-point input element \|x\| after normalization. This is the unbiased exponent of x used in the representation of the floating-point value, such that, for positive x, x = significand × 2<sup>exponent</sup>. The integer results are placed in elements of the destination vector that have the same width (esize) as the floating-point input elements: - If x is normal, the result is the base 2 logarithm of x. - If x is subnormal, the result corresponds to the normalized representation. - If x is infinite, the result is 2<sup>(esize-1)</sup>-1. - If x is ±0.0 or NaN, the result is -2<sup>(esize-1)</sup>. Inactive elements in the destination vector register remain unmodified or are set to zero, depending on whether merging or zeroing predication is selected. It has encodings from 2 classes: [Merging](#iclass_merging) and [Zeroing](#iclass_zeroing)
