## CINC

Conditional increment This instruction returns, in the destination register, the value of the source register incremented by 1 if the condition is TRUE, and otherwise returns the value of the source register. This is an alias of [CSINC](csinc.html). This means: - The encodings in this description are named to match the encodings of [CSINC](csinc.html). - The description of [CSINC](csinc.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [CSINC](csinc.html) gives the operational pseudocode for this instruction.
