## MOV (SIMD&FP scalar, unpredicated)

Move indexed element or SIMD&FP scalar to vector (unpredicated) This instruction unconditionally broadcasts the SIMD&FP scalar into each element of the destination vector. This instruction is unpredicated. This is an alias of [DUP (indexed)](dup_z_zi.html). This means: - The encodings in this description are named to match the encodings of [DUP (indexed)](dup_z_zi.html). - The description of [DUP (indexed)](dup_z_zi.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [DUP (indexed)](dup_z_zi.html) gives the operational pseudocode for this instruction.
