## NEGS

Negate, setting flags This instruction negates an optionally-shifted register value, and writes the result to the destination register. It updates the condition flags based on the result. This is an alias of [SUBS (shifted register)](subs_addsub_shift.html). This means: - The encodings in this description are named to match the encodings of [SUBS (shifted register)](subs_addsub_shift.html). - The description of [SUBS (shifted register)](subs_addsub_shift.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [SUBS (shifted register)](subs_addsub_shift.html) gives the operational pseudocode for this instruction.
