## STLR

Store-release register This instruction stores a 32-bit word or a 64-bit doubleword to a memory location, from a register. The instruction also has memory ordering semantics as described in Load-Acquire, Store-Release. For information about addressing modes, see Load/Store addressing modes. It has encodings from 2 classes: [No offset](#iclass_no_offset) and [Pre-index](#iclass_pre_index)
