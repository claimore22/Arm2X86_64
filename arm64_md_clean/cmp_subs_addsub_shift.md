## CMP (shifted register)

Compare (shifted register) This instruction subtracts an optionally-shifted register value from a register value. It updates the condition flags based on the result, and discards the result. This is an alias of [SUBS (shifted register)](subs_addsub_shift.html). This means: - The encodings in this description are named to match the encodings of [SUBS (shifted register)](subs_addsub_shift.html). - The description of [SUBS (shifted register)](subs_addsub_shift.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.
