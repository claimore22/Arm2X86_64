## UMNEGL

Unsigned multiply-negate long This instruction multiplies two 32-bit register values, negates the product, and writes the result to the 64-bit destination register. This is an alias of [UMSUBL](umsubl.html). This means: - The encodings in this description are named to match the encodings of [UMSUBL](umsubl.html). - The description of [UMSUBL](umsubl.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [UMSUBL](umsubl.html) gives the operational pseudocode for this instruction.
