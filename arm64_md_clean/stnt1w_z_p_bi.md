## STNT1W (scalar plus immediate, single register)

Contiguous store non-temporal words from vector (immediate index) This instruction performs a contiguous non-temporal store of words from elements of a vector register to the memory address generated by a 64-bit scalar base and immediate index in the range -8 to 7 that is multiplied by the vector's in-memory size, irrespective of predication, and added to the base address. Inactive elements are not written to memory. A non-temporal store is a hint to the system that this data is unlikely to be referenced again soon.
