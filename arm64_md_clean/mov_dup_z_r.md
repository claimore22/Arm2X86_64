## MOV (scalar, unpredicated)

Move general-purpose register to vector elements (unpredicated) This instruction unconditionally broadcasts the general-purpose scalar source register into each element of the destination vector. This instruction is unpredicated. This is an alias of [DUP (scalar)](dup_z_r.html). This means: - The encodings in this description are named to match the encodings of [DUP (scalar)](dup_z_r.html). - The description of [DUP (scalar)](dup_z_r.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [DUP (scalar)](dup_z_r.html) gives the operational pseudocode for this instruction.
