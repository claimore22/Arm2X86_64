## STNT1H (scalar plus scalar, single register)

Contiguous store non-temporal halfwords from vector (scalar index) This instruction performs a contiguous non-temporal store of halfwords from elements of a vector register to the memory address generated by a 64-bit scalar base and scalar index that is multiplied by 2 and added to the base address. After each element access the index value is incremented, but the index register is not updated. Inactive elements are not written to memory. A non-temporal store is a hint to the system that this data is unlikely to be referenced again soon.
