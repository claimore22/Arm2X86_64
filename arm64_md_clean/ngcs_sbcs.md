## NGCS

Negate with carry, setting flags This instruction negates the sum of a register value and the value of NOT (Carry flag), and writes the result to the destination register. It updates the condition flags based on the result. This is an alias of [SBCS](sbcs.html). This means: - The encodings in this description are named to match the encodings of [SBCS](sbcs.html). - The description of [SBCS](sbcs.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [SBCS](sbcs.html) gives the operational pseudocode for this instruction.
