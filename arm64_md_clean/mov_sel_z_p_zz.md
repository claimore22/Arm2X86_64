## MOV (vector, predicated)

Move vector elements (predicated) This instruction moves elements from the source vector to the corresponding elements of the destination vector. Inactive elements in the destination vector register remain unmodified. This is an alias of [SEL (vectors)](sel_z_p_zz.html). This means: - The encodings in this description are named to match the encodings of [SEL (vectors)](sel_z_p_zz.html). - The description of [SEL (vectors)](sel_z_p_zz.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [SEL (vectors)](sel_z_p_zz.html) gives the operational pseudocode for this instruction.
