## ST1D (vector plus immediate)

Scatter store doublewords from a vector (immediate index) This instruction performs a scatter store of doublewords from the Active elements of a vector register to the memory addresses generated by a vector base plus immediate index. The index is a multiple of 8 in the range 0 to 248. Inactive elements are not written to memory. This instruction is illegal when executed in Streaming SVE mode, unless FEAT_SME_FA64 is implemented and enabled.
