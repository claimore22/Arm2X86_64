## TST (immediate)

Test bits (immediate) This instruction performs a bitwise AND between a register value and an immediate value, and discards the results. It updates the condition flags based on the result. This is an alias of [ANDS (immediate)](ands_log_imm.html). This means: - The encodings in this description are named to match the encodings of [ANDS (immediate)](ands_log_imm.html). - The description of [ANDS (immediate)](ands_log_imm.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [ANDS (immediate)](ands_log_imm.html) gives the operational pseudocode for this instruction.
