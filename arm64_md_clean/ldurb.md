## LDURB

Load register byte (unscaled) This instruction calculates an address from a base register and an immediate offset, loads a byte from memory, zero-extends it, and writes it to a register. For information about addressing modes, see Load/Store addressing modes.

#### Decode

let offset : bits(64) = SignExtend{}(imm9);

### Operation
