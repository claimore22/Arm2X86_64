## CMPP

Compare with tag This instruction subtracts the 56-bit address held in the second source register from the 56-bit address held in the first source register, updates the condition flags based on the result of the subtraction, and discards the result. This is an alias of [SUBPS](subps.html). This means: - The encodings in this description are named to match the encodings of [SUBPS](subps.html). - The description of [SUBPS](subps.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.
