## ADD (to array, array and multiple vectors)

Multi-vector accumulate to ZA array vectors This instruction destructively adds all elements of the two or four source vectors to the corresponding elements of the ZA single-vector groups. The single-vector group within each half of or each quarter of the ZA array is selected by the sum of the vector select register and offset, modulo half or quarter the number of ZA array vectors. The vector group symbol, VGx2 or VGx4, indicates that the ZA operand consists of two or four ZA single-vector groups respectively. The vector group symbol is preferred for disassembly, but optional in assembler source code. This instruction is unpredicated. ID_AA64SMFR0_EL1.I16I64 indicates whether the 64-bit integer variant is implemented. It has encodings from 2 classes: [Two ZA single-vectors](#iclass_two_za_single_vectors) and [Four ZA single-vectors](#iclass_four_za_single_vectors)
