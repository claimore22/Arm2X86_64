## MOV (SIMD&FP scalar, predicated)

Move SIMD&FP scalar register to vector elements (predicated) This instruction moves the SIMD & floating-point scalar source register to each Active element in the destination vector. Inactive elements in the destination vector register remain unmodified. This is an alias of [CPY (SIMD&FP scalar)](cpy_z_p_v.html). This means: - The encodings in this description are named to match the encodings of [CPY (SIMD&FP scalar)](cpy_z_p_v.html). - The description of [CPY (SIMD&FP scalar)](cpy_z_p_v.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.
