## SMLALL (multiple and indexed vector)

Multi-vector signed integer multiply-add long long by indexed element This instruction multiplies each signed 8-bit or 16-bit element in the one, two, or four first source vectors by each signed 8-bit or 16-bit indexed element of the second source vector, widens each product to 32 bits or 64 bits, and destructively adds these values to the corresponding 32-bit or 64-bit elements of the ZA quad-vector groups. The elements within the second source vector are specified using an immediate element index that selects the same element position within each 128-bit vector segment. The index range is from 0 to one less than the number of elements per 128-bit segment. The quad-vector group within all of, each half of, or each quarter of the ZA array is selected by the sum of the vector select register and offset range, modulo all, half, or quarter the number of ZA array vectors. The vector group symbol, VGx2 or VGx4, indicates that the ZA operand consists of two or four ZA quad-vector groups respectively. The vector group symbol is preferred for disassembly, but optional in assembler source code. This instruction is unpredicated. ID_AA64SMFR0_EL1.I16I64 indicates whether the 16-bit integer variant is implemented. It has encodings from 6 classes: [One ZA quad-vector of 32-bit elements](#iclass_one_za_quad_vector_of_32_bit_elements) , [One ZA quad-vector of 64-bit elements](#iclass_one_za_quad_vector_of_64_bit_elements) , [Two ZA quad-vectors of 32-bit elements](#iclass_two_za_quad_vectors_of_32_bit_elements) , [Two ZA quad-vectors of 64-bit elements](#iclass_two_za_quad_vectors_of_64_bit_elements) , [Four ZA quad-vectors of 32-bit elements](#iclass_four_za_quad_vectors_of_32_bit_elements) and [Four ZA quad-vectors of 64-bit elements](#iclass_four_za_quad_vectors_of_64_bit_elements)
