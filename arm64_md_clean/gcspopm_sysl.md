## GCSPOPM

Guarded Control Stack pop This instruction loads the 64-bit doubleword that is pointed to by the current GCS pointer register, writes it to the destination register, and increments the current GCS pointer register by the size of a GCS procedure return record. For more information, see GCSPOPM, Guarded Control Stack Pop. This is an alias of [SYSL](sysl.html). This means: - The encodings in this description are named to match the encodings of [SYSL](sysl.html). - The description of [SYSL](sysl.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [SYSL](sysl.html) gives the operational pseudocode for this instruction.
