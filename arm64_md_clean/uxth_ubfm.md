## UXTH

Unsigned extend halfword This instruction extracts a 16-bit value from a register, zero-extends it to the size of the register, and writes the result to the destination register. This is an alias of [UBFM](ubfm.html). This means: - The encodings in this description are named to match the encodings of [UBFM](ubfm.html). - The description of [UBFM](ubfm.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [UBFM](ubfm.html) gives the operational pseudocode for this instruction.
