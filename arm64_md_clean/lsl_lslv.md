## LSL (register)

Logical shift left (register) This instruction shifts a register value left by a variable number of bits, shifting in zeros, and writes the result to the destination register. The value of the second source register modulo the register size in bits gives the number of bits by which the first source register is left-shifted. This is an alias of [LSLV](lslv.html). This means: - The encodings in this description are named to match the encodings of [LSLV](lslv.html). - The description of [LSLV](lslv.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.
