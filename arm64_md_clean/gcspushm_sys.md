## GCSPUSHM

Guarded Control Stack push This instruction decrements the current GCS pointer register by the size of a GCS procedure return record and stores an entry to the Guarded Control Stack. For more information, see GCSPUSHM, Guarded Control Stack Push. This is an alias of [SYS](sys.html). This means: - The encodings in this description are named to match the encodings of [SYS](sys.html). - The description of [SYS](sys.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [SYS](sys.html) gives the operational pseudocode for this instruction.
