## PRFH (scalar plus vector)

Gather prefetch halfwords (scalar plus vector) This instruction performs a gather prefetch of halfwords from the active memory addresses generated by a 64-bit scalar base plus vector index. The index values are optionally first sign-extended or zero-extended from 32 to 64 bits and then multiplied by 2. Inactive addresses are not prefetched from memory. The \ operand specifies the prefetch hint as follows: - Access type: - PLD for prefetch for load. - PST for prefetch for store. - Target cache level: - L1 for Level 1 cache. - L2 for Level 2 cache. - L3 for Level 3 cache. - Policy: - KEEP for retained or temporal prefetch, allocated in the cache normally. - STRM for streaming or non-temporal prefetch, for data that is used only once. This instruction is illegal when executed in Streaming SVE mode, unless FEAT_SME_FA64 is implemented and enabled. It has encodings from 3 classes: [32-bit scaled offset](#iclass_32_bit_scaled_offset) , [32-bit unpacked scaled offset](#iclass_32_bit_unpacked_scaled_offset) and [64-bit scaled offset](#iclass_64_bit_scaled_offset)
