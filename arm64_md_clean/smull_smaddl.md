## SMULL (32-bit)

Signed multiply long This instruction multiplies two 32-bit register values, and writes the result to the 64-bit destination register. This is an alias of [SMADDL](smaddl.html). This means: - The encodings in this description are named to match the encodings of [SMADDL](smaddl.html). - The description of [SMADDL](smaddl.html) gives the operational pseudocode, any constrained unpredictable behavior, and any operational information for this instruction.

### Operation

The description of [SMADDL](smaddl.html) gives the operational pseudocode for this instruction.
